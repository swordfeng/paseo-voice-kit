Voice Kit 在守护进程所在的机器上运行语音识别和语音合成，并让 Paseo 的听写和语音模式使用它们。除非你自己添加远程语音服务，音频不会离开这台机器。

## 工作方式

Voice Kit 会在守护进程旁启动一个小型原生语音服务（voicekit）。模型就绪后，它会把听写、语音模式的“听”和“说”切换到这个服务。服务启动、模型下载或出现故障时，Paseo 会改用内置语音，所以语音功能不会中断。关闭或移除 Voice Kit 会恢复你之前的语音设置，包括 OpenAI 密钥。

如果你在“设置 > 语音”中自行更改了某项语音设置，Voice Kit 会停止管理该功能，直到你在它的页面上选择“使用 Voice Kit”。

## 设置

语音服务是一个单独的原生程序。项目在 GitHub 上的 v0.1.0 版本提供了 macOS（Apple 芯片和 Intel）、Linux（x64 和 arm64）和 Windows（x64）的预构建服务程序。Voice Kit 首次启动时，会在下载适合你平台的版本前征求你的同意，说明下载来源，并按固定的校验和验证。如果拒绝，Voice Kit 会关闭，Paseo 继续使用内置语音。你也可以在“程序路径”设置中指向自己构建的版本；安装和构建说明见 [README](https://github.com/swordfeng/paseo-voice-kit#readme)。

内置的 Qwen3-TTS 模型在 Voice Kit 自己的原生进程中运行。你添加的 MLX 版 Qwen3-TTS 模型需要 Apple 芯片、macOS 14 或更高版本的 Mac，以及带 MLX 的 Python 3.12 运行环境，需用源码仓库中的安装脚本单独安装；Voice Kit 不会自行安装 Python 包。

需要 Paseo 0.15.4 或更高版本，并已启用插件。目前日常使用的平台是 Apple 芯片的 macOS。每个发布平台都通过了自动化测试：构建服务程序、运行原生测试、按 Voice Kit 的方式解包，并用替代引擎检查语音服务。Windows、Intel Mac 和 Linux GPU 上的实际语音识别与合成尚未验证。

## 模型

默认设置无需更改即可支持多种语言：

- 听：Voice Kit 会为这台机器选定一次默认的多语言模型，听写和语音模式都使用它，直到你选择其他模型；你的选择之后保持不变。在 Mac 上是在 GPU 上运行的 Whisper turbo（约 100 种语言，带标点）。在 Linux 和 Windows 上，Voice Kit 会检查一次 GPU，足够快就使用 Whisper turbo，否则在 CPU 上使用 Qwen3-ASR（约 30 种语言）。听写和语音模式也可以分别选择不同的模型。
- 说：你可以选择使用哪些语音模型以及它们的顺序；每句话使用列表中第一个原生会说该语言的已启用模型。新安装只启用 Supertonic 3（31 种语言，在 CPU 上运行）。Qwen3-TTS 0.6B 和 1.7B 支持 10 种语言；它们是可选的，启用后才下载，有 GPU 时使用 GPU，目前只在 Apple 芯片的 Mac 上测试过。如果回复中有已启用模型都不会说的语言，整条回复会被拒绝，而不是用错误的发音读出，页面会说明哪个模型会说它。可从六个声音（Mia、Lena、Nora、Leo、Kai、Owen）中选择，每个声音在各模型中搭配相近的声音；也可以按模型自己选择。
- 其他选择：适合欧洲语言的 Parakeet v3、适合亚洲和中东语言的 Dolphin small、SenseVoice 和 Whisper small。每张模型卡片都会说明它擅长什么以及有哪些局限。

模型下载到 `~/.paseo/plugin-data/voice-kit/models`，并按固定的校验和验证。除非关闭“自动下载模型”，选择模型后会立即下载。Parakeet v3 和 SenseVoice 与 Paseo 共用同一份文件：只下载一次，两边都能看到，移除时 Paseo 那边也会一起移除。下载的模型保留各自的许可证，见 MODEL_LICENSES.md；Supertonic 3 的 OpenRAIL-M 许可证包含使用限制。

在 Mac 上，可以在“听”标签页中已选 Whisper 模型的卡片上打开神经网络引擎。它需要下载 1.2 GB，并进行一次耗时几分钟的设置，之后 Whisper 速度约快 2.5 倍。默认关闭。

## 你自己的模型

在“你的模型”中，可以添加来自 Hugging Face 的模型（Voice Kit 能识别 Whisper 和 sherpa-onnx 模型，固定到具体版本并校验大文件）、其他兼容 OpenAI 的语音服务、Whisper 模型文件或网址，以及 sherpa-onnx 模型文件夹或压缩包。语音服务的 API 密钥保存在守护进程主机上、只有你的用户可读的文件中，并作为插件设置同步给已连接的 Paseo 应用。

## 设置页面

可以从侧边栏底部的 Voice Kit 行（圆点表示状态）、输入 /voicekit、命令中心或“设置 > 插件”打开 Voice Kit。页面语言跟随 Paseo 应用的语言。

- 听：哪些听的功能使用 Voice Kit、它们的模型、语言和词汇，然后是语音识别模型和你自己的模型。
- 说：语音模式的“说”、声音、语速和试听，然后是语音模型的有序列表、语言覆盖和可添加的语音模型。
- 高级：侧边栏显示、加速、卸载闲置模型、端口、自定义服务程序和服务日志。每个模型在首次需要时加载，默认闲置 10 分钟后各自卸载。

## 限制

- 服务只监听 127.0.0.1，只响应发往本机地址的请求，并要求使用每次启动都会更换的令牌。
- 为了让语音模式的轮次检测正常工作，Voice Kit 会把守护进程配置中的 `providers.local.modelsDir` 设为 Paseo 的默认模型文件夹，并让守护进程重新加载一次配置。
- 守护进程上设置 Paseo 语音选项的环境变量优先生效；这些功能会显示为已锁定。
