Voice Kit 在运行 Paseo 守护进程的电脑上提供语音识别和语音合成，供 Paseo 的听写和语音模式使用。

## 工作方式

Voice Kit 会在守护进程所在的电脑上运行一个语音服务 voicekit。模型准备好后，Voice Kit 会让听写、语音模式的“听”和“说”改用它。在服务启动、模型下载期间，或者出现故障时，Paseo 会回到你之前的语音设置；如果之前没有设置，则使用 Paseo 自带的语音。关闭或移除 Voice Kit 会恢复你之前的语音设置，包括 OpenAI 密钥。

如果你在“设置 > 语音”中自己改了某项语音设置，Voice Kit 就不再接管这项功能，直到你在它的页面上点“使用 Voice Kit”。

## 安装与要求

语音服务是一个单独的程序。macOS（Apple 芯片和 Intel）、Linux（x64 和 arm64）和 Windows（x64）的现成版本来自本项目在 GitHub 上的 v0.1.1 版本。Voice Kit 下载某个版本的语音服务之前会先征求你的同意，说明下载来源，并用固定的校验和核对下载的文件。插件更新后如果需要新版本的语音服务，会再次征求同意。如果你拒绝，不会下载任何东西，Voice Kit 会关闭，你的语音设置保持原样。你也可以在“程序路径”设置中指定自己构建的版本；构建方法见 [README](https://github.com/swordfeng/paseo-voice-kit#readme)。

内置的 Qwen3-TTS 模型运行在语音服务自带的一个辅助程序中。你添加的 MLX 版 Qwen3-TTS 模型运行在它自带的另一个辅助程序中，需要 Apple 芯片、macOS 14 或更高版本的 Mac。模型权重和其他模型一样单独下载。

Voice Kit 需要 Paseo 0.15.4 或更高版本，并已启用插件。0.1.1 版已在 Apple 芯片的 Mac 和配备 NVIDIA 显卡的 Windows 上手动检查过，两者都做过全新安装；在 Linux 上检查了 CPU，并在 WSL 下检查了 NVIDIA 显卡。每个发布平台都会自动用真实模型在 CPU 上做检查。Intel Mac、Linux 原生显卡驱动以及 AMD 或 Intel 显卡上的 GPU 语音尚未检查。

## 数据去向

你的语音在这台电脑上转成文字，回复也在这台电脑上朗读。除非你自己添加了外部语音服务，Voice Kit 不会把任何内容发给外部语音服务。转出来的文字仍会作为你的消息进入 Paseo，再像你打字输入时一样，发给你的代理所用的服务商。

如果你在“你的模型”中添加了远程语音服务，该服务会收到它要处理的音频或文字、你的词汇提示，以及你为它填写的 API 密钥。

## 模型

默认设置无需改动即可支持多种语言。

听：

- Voice Kit 会为这台电脑选定一个多语言模型，听写和语音模式都用它，直到你另选。Mac 上是 Whisper turbo（约 100 种语言，带标点），在 GPU 上运行。在 Linux 和 Windows 上，Voice Kit 会测一次 GPU：速度够快就用 Whisper turbo，否则在 CPU 上使用 Qwen3-ASR（约 30 种语言）。
- 听写和语音模式可以各选一个模型。
- 其他模型：Parakeet v3 适合欧洲语言，Dolphin small 适合亚洲和中东语言，另有 SenseVoice 和 Whisper small。每个模型的卡片会说明它擅长什么、有哪些不足。

说：

- 你可以选择使用哪些语音模型，并排好顺序。默认情况下，每句话由列表中第一个本身就会说这种语言的已启用模型来读。你也可以为某种语言另选首选模型，或者允许用不会说这种语言的模型来近似朗读。
- 如果没有做上述设置，而回复里有已启用模型都不会说的语言，Voice Kit 不会朗读这条回复，以免用错误的发音去读；页面上会说明哪个模型会说这种语言。很短、无法判断语言的拉丁字母文字会按英语朗读。
- 新安装只启用 Supertonic 3：支持 31 种语言，在 CPU 上运行。Qwen3-TTS 0.6B 和 1.7B 支持 10 种语言。它们是可选的，启用后才下载，能用 GPU 时使用 GPU（已在 Apple 芯片的 Mac 和 NVIDIA 显卡上检查过）。如果 GPU 无法运行它们，会改在 CPU 上运行，并在模型卡片上说明。
- 每个语音模型有自己的声线，可在它的卡片上选择和试听。默认情况下，Supertonic 3 和 Qwen3-TTS 使用两个相近的声线，所以混合多种语言的回复听起来也相似。

内置模型从 Hugging Face 和 GitHub 下载到 Voice Kit 的数据文件夹（默认是 `~/.paseo/plugin-data/voice-kit/models`），并用固定的校验和核对。除非你关闭“自动下载模型”，选择模型后会立即下载。Parakeet v3 和 SenseVoice 使用 Paseo 自己的那一份：只下载一次，Voice Kit 和 Paseo 都能看到，移除时 Paseo 那边也会一起移除。下载的模型保留各自的许可证，见 MODEL_LICENSES.md；Supertonic 3 的 OpenRAIL-M 许可证包含使用限制。

在 Mac 上，可以在“高级”的实验性选项中为 Whisper 打开神经网络引擎。它只加快 Whisper；不打开时，Whisper 使用 GPU。打开后需要下载约 1.2 GB，并做一次耗时几分钟的准备。默认关闭。

## 你自己的模型

在“你的模型”中，可以添加来自 Hugging Face 的 Whisper 或 sherpa-onnx 模型（Voice Kit 会固定使用你添加时的版本，并核对其中的大文件）、其他兼容 OpenAI 接口的语音服务、Whisper 模型文件或网址，以及 sherpa-onnx 模型文件夹或压缩包。语音服务的 API 密钥保存在守护进程所在的电脑上，存放在只有你的用户账户能读取的文件中。你可以填写或更换密钥，但它不会再发回 Paseo 应用。

## 设置页面

可以从侧边栏底部的 Voice Kit 入口（圆点表示状态）、输入 /voicekit、命令中心或“设置 > 插件”打开 Voice Kit。页面使用 Paseo 应用的语言。

- 听：听写和语音模式的“听”是否使用 Voice Kit，以及它们的模型、语言和词汇；然后是语音识别模型，包括你自己的模型。
- 说：语音模式的“说”、语速和“试读一段回复”；然后是按顺序排列的语音模型，每个都带声线和试听，接着是它们覆盖的语言，以及可以添加的语音模型。
- 高级：侧边栏入口、加速、卸载闲置模型、端口、自己的服务程序和服务日志。每个模型在第一次需要时加载，默认闲置 10 分钟后自动卸载。

## 限制

- 语音服务只监听 127.0.0.1，只响应发往本机的请求。除健康检查外，每个请求都需要令牌，令牌在服务每次启动时更换。
- 为了让语音模式的轮次检测正常工作，如果守护进程配置中没有设置 `providers.local.modelsDir`，Voice Kit 会把它设为 Paseo 的默认模型文件夹；它启动时还可能让守护进程重新加载一次配置。
- 守护进程上设置 Paseo 语音选项的环境变量优先生效，这些功能会显示为已锁定。
